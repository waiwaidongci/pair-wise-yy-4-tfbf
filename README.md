# 水下考古潜次复核台

直接打开 `index.html` 使用（纯静态页面，无需构建）。数据保存在浏览器 `localStorage`。

## 功能

- **标记平面图**：点击沉船平面图加点，支持类型筛选、编辑、删除、潜次时间线、JSON 导出（沿用原有操作）。
- **潜次复核台**：按潜次汇总标记数量、深度范围、保存状态与潜次更新时间；可按「待复核 / 已签字」筛选。
- **签字规则**：标记缺少编号、深度或保存状态时签字按钮禁用；潜水长姓名必填，可填写复核意见。
- **签字失效**：已签字潜次中的标记一旦新增、编辑、移除或改划潜次，签字自动失效并回到待复核，旧签字保留在该潜次履历中。
- **导入备份**：选择队里导出的 JSON（支持完整档案或旧版纯标记数组），按潜次号和更新时间合并：
  - 备份较旧、或本地潜次已签字 → 保留本地原档，并在冲突列表中列出原因与双方更新时间；
  - 备份较新且本地未签字 → 以备份替换该潜次，签字履历合并保留。
- **导出**：标记清单 CSV、复核汇总 CSV 各一份；另保留原 JSON 导出（现包含复核记录的完整档案）。

## 文件结构

- `index.html` — 页面结构、样式与视图切换
- `js/store.js` — 档案整理：持久化、潜次汇总、签字/失效履历、备份合并
- `js/review.js` — 潜次复核台界面：筛选、签字表单、冲突列表
- `js/export.js` — 标记清单 CSV、复核汇总 CSV、JSON 导出
- `js/app.js` — 标记平面图：加点、编辑、移除、筛选、时间线

旧版本地数据键 `zfl30Marks` 在首次打开时自动迁移到新档案键 `zfl30Archive.v1`。

## 自测

`js/store.js` 为纯逻辑模块，可用 Node 配合 localStorage/crypto shim 测试（签字校验、失效履历、按潜次合并与冲突保留等）。
