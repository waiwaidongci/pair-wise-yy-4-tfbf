# 水下考古潜水记录 · 潜次复核台

纯静态页面，直接打开 `index.html` 即可使用（也可用 `npx http-server` 等本地服务器打开），数据保存在浏览器 localStorage。

## 功能

**平面图标记（首页）**
- 点击沉船平面图添加标记，支持编辑、删除、按类型筛选、潜次时间线
- 标记字段：编号、类型、潜次、深度、朝向、保存状态、备注
- 列表/时间线中可看到每个标记所属潜次的复核状态（待复核 / 资料不齐 / 已签字）
- 对已签字潜次内的标记新增、编辑、移除时会二次确认；确认后该潜次签字自动失效

**潜次复核台（第二个页签）**
- 按潜次汇总标记数量、每条标记的深度与保存状态，缺失字段逐项标出
- 标记缺必填资料（编号/类型/潜次/深度/保存状态）时不能签字
- 潜水长可填写复核意见并签字
- 可按复核状态筛选：待复核 / 已签字 / 资料不齐
- 已签字潜次的标记一旦改动，签字立即失效、潜次回到待复核；旧签字保留在该潜次的签字履历中（标注「已失效」及失效原因）

**导入备份（顶部「导入备份」）**
- 接受旧版标记数组 JSON，或本系统导出的复核汇总 JSON
- 按标记 id（其次按 潜次号 + 编号）匹配，按 `updatedAt` 更新时间合并：
  - 备份记录较旧 → 保留原档，列入冲突
  - 原档（或目标潜次）已签字 → 保留原档，列入冲突
  - 备份较新且潜次未签字 → 采用备份
- 冲突清单显示在复核台顶部，可手动清空

**导出（顶部按钮，共三份）**
1. `导出JSON`：标记原始 JSON（`dive-marks.json`，与旧版格式一致）
2. `导出标记清单`：CSV 清单（含 BOM，Excel 可直接打开）
3. `导出复核汇总`：各潜次状态、签字、意见、履历的汇总 JSON，同时是完整备份，可回导合并

## 文件结构

- `index.html` — 页面骨架（平面图页 + 复核台页两个页签）
- `css/styles.css` — 全部样式
- `js/archive.js` — 档案层：存取、潜次汇总、签字/失效规则、履历、备份合并与冲突
- `js/review.js` — 潜次复核台界面
- `js/export.js` — 三份导出
- `js/app.js` — 平面图加点/编辑/移除/筛选/时间线及导入入口
